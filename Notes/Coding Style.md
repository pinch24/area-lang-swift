# Swift 코딩 원칙

## 안 해도 되는 것은 하지 말기
- self, ...;, (...)와 같이 표기법에서 없어도 되는 것들은 가능하면 제거
(문장 마지막의 return 키워드는 한 줄 코드 일 때 제거)

## 이름으로 맥락을 서술하기
- API 모듈에서 메소드는 REST 함수 이름으로 시작한다.
- API를 사용하는 메소드는 fetch/manipulation으로 함수 이름을 시작한다.
- 파일을 다루는 메소드는 read/save로 함수 이름을 시작한다

## 주석은 가능하면 한글로
- 설명은 한글로
- 영어가 더 명확한 경우에는 영어로

## 모듈화의 장점
- 단순해진다. (구조가)

## 모듈화의 단점
- 복잡해진다. (기능이)

## 코딩하는 방법
1. 깊이, 충분히 생각한 다음 시작한다.
2. 일단 시작하고 감각이 들어오면 리팩토링 한다.
